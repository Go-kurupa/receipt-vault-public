# Receipt Vault — 確認して訂正できる、AIにつながる領収書保管

個人事業の領収書・レシートを保管し、ClaudeやChatGPTから検索・整理できるようにした個人用アプリです。
スマートフォンで撮った領収書を、その場で保管します。作者はPixelのホーム画面アプリとして使っています。

**会話で探し、下書きを確認し、元の記録を残して訂正する。** AIから記録を扱うための手順と権限を実装しています。

→ [養鶏場の業務アプリと周辺ツールの全体像](https://github.com/Go-kurupa/portfolio-public)

## このアプリで扱う課題

領収書は保管した後にも、検索、科目の整理、メモの訂正が必要になります。
会話から整理できるようにする際、変更対象と内容を人が確かめ、訂正前の記録もたどれる形にしました。

| 最初に知りたいこと | 読むところ |
|---|---|
| 使う流れ | 下の「利用の流れ」 |
| 訂正・版管理・権限の設計 | 下の「設計で大事にしたこと」と実装へのリンク |
| 実行条件と確認コマンド | [開発者向けガイド](./docs/development.md) |

MCPは、ClaudeやChatGPTなどから検索・整理の機能を呼び出すための接続口です。

## 何ができるか

| 機能 | 内容 |
|---|---|
| 保管・検索 | 画面から領収書を保管し、日付・取引先・金額・科目で検索 |
| 訂正の履歴 | 元の記録を残し、新しい版を追記。集計では最新版を使う |
| AIとの接続 | MCPを通して、Claude・ChatGPT等から検索・集計・整理 |
| 訂正の確認 | 下書きで変更内容を確認し、了承後に適用する手順 |

## 利用の流れ：科目とメモを整理する

以下は説明用の架空例です。実データや実行ログではありません。

| 手順 | 人とアプリのやり取り |
|---|---|
| 1. 探す | 「未仕訳の領収書を見せて」と依頼し、候補を確認する |
| 2. 下書き | 架空の1件について「科目を消耗品費、メモを梱包用資材にしたい」と依頼する |
| 3. 確認 | 変更前後を見比べ、対象と内容が合っているかを人が確認する |
| 4. 適用 | 了承後に適用し、新しい版と結果を確認する |

この整理機能では、科目・メモ・案件・按分・状態・仕訳番号を変更対象にしています。
日付・金額・取引先の訂正、削除、新規登録は画面から行います。

## 設計で大事にしたこと

- **下書きと適用を分ける** — `preview_update_receipt` と `apply_update_receipt` に処理を分け、変更内容を確認する手順を用意しました。
- **訂正を追記として残す** — 元の記録を消さず、新しい版を保存します。
- **鍵ごとの権限** — 読み取り専用と整理用の権限を分け、書込みを止めるスイッチも設けています。
- **再送時の重複防止** — 要求ログと証憑を一つのデータベース更新として保存し、同じ要求が再送されても二重処理にしないようにしています。
- **取引先名やメモをデータとして扱う** — AIに渡す説明に、記録の文字列を指示として扱わない旨を記載しています。
- **濫用への備え** — 認証前後の回数制限、結果サイズ、同時確定の条件を検証しています。

## 構成と見どころ

```text
スマートフォンのアプリ ─ React / TypeScript / Vite ─ Firebase
                                                        │
                                 Cloud Functions ───────┤ 訂正・版管理・重複防止
                                                        │
Claude / ChatGPT ─ MCPサーバー ──────────────────────────┘ 検索・集計・整理
                  OAuth・鍵の権限・回数制限
```

| 収録場所 | 内容 |
|---|---|
| `src/` | 画面と画面側のテスト |
| `functions/` | 訂正・版管理・要求の重複防止 |
| `mcp/` | 検索・集計・整理、認証、権限、回数制限 |

最初に読む場合は、[整理処理](./mcp/src/write/tools.ts)、[版管理](./functions/src/versioning.ts)、[要求の重複防止](./functions/src/idempotency.ts)が中心です。
